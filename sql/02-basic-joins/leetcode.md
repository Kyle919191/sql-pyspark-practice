# SQL 50 — Basic Joins

https://leetcode.com/studyplan/top-sql-50/

| # | Problem | Pattern |
| ---: | --- | --- |
| 1378 | Replace Employee ID With The Unique Identifier | LEFT JOIN, keep NULLs |
| 1068 | Product Sales Analysis I | INNER JOIN lookup |
| 1581 | Customer Who Visited but Did Not Make Any Transactions | anti-join + COUNT |
| 197 | Rising Temperature | self-join on date |
| 1661 | Average Time of Process per Machine | self-join start/end, AVG |
| 577 | Employee Bonus | LEFT JOIN + filter bonus |
| 1280 | Students and Examinations | CROSS JOIN + LEFT JOIN + COUNT |
| 570 | Managers with at Least 5 Direct Reports | self-join or GROUP BY manager |
| 1934 | Confirmation Rate | LEFT JOIN + AVG of CASE |

Do local problems first, then these in order. 1280 and 1934 are the ones people stall on — grain and NULL rates.

# Advanced SQL

Read these **in order**. Each lesson is a pattern that shows up over and over in Advanced SQL 50 and in real analytics work.

1. `01-window-functions.md` — rank, running sum, lag/lead
2. `02-ctes.md` — named steps, including recursive
3. `03-gaps-islands.md` — consecutive ranges
4. `04-pivot.md` — rows to columns with CASE
5. `05-trees-hierarchy.md` — org charts and recursive walks

Then local problems in `problems/`, then the Premium list in `leetcode.md`.

You do **not** need LeetCode Premium to learn this track. The local problems cover the same patterns.
